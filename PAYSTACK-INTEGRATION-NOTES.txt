IMPORTANT BEFORE GOING LIVE
===========================

Open js/paystack-donation.js and replace this line:

const PAYSTACK_PUBLIC_KEY = "pk_test_REPLACE_WITH_YOUR_PAYSTACK_PUBLIC_KEY";

with your real Paystack public key, for example:

const PAYSTACK_PUBLIC_KEY = "pk_live_xxxxxxxxxxxxxxxxxxxxx";

Use pk_test_... while testing.
Use pk_live_... only when the Paystack account is approved and ready for live donations.

Recommended production step:
For proper accounting and fraud control, add server-side payment verification using Paystack's Verify Transaction endpoint or webhooks. This front-end integration opens checkout and captures the payment reference, but final confirmation should be verified from the server or Paystack dashboard.
